# 小北 · 智能语音助手（华强北手表专用）

在 Android 华强北手表上，让"小北"像华为语音助手一样随叫随到：

> 只要对着手表说 **“小北 小北”**，小北就会被唤醒并回答："在呢，请说"
> 然后你可以说 **“今天天气怎么样”**、**“设置一个提醒”**、**“5 加 3 等于几”**……
> 小北会调用 **千问 AI（通义千问）** 理解并回答，然后用 **中文语音** 播报出来。

**完全免费**，核心离线唤醒不需联网、不用花一分钱购买任何 API。

---

## 工作原理

| 环节 | 方案 | 是否付费 |
|------|------|---------|
| 语音唤醒（离线、永远监听"小北"） | Vosk 开源离线语音识别 | 免费 |
| AI 大脑（理解问题并回答） | 阿里云百炼·通义千问 qwen-turbo | 免费额度 |
| 语音播报（念出答案） | 系统自带文字转语音 TTS | 免费 |

## 一、需要准备什么？

1. 一台华强北智能手表（Android 系统）
2. 一个 GitHub 账号（免费，用于云端自动编译 APK）
3. 一台电脑（用于上传代码到 GitHub）

> 不需要安装 Android Studio，不需要装 JDK —— 编译在 GitHub 云端自动完成。

---

## 二、获取千问 API Key（免费）

1. 用电脑或手机浏览器打开：https://bailian.aliyun.com
2. 用支付宝 / 淘宝账号登录阿里云
3. 在控制台左侧找到 **"API-KEY"** → 点 **"创建 API Key"**
4. 复制生成的 Key（形如 `sk-xxxxxxxxxxxx`），保存好
5. 若是新用户，百炼提供免费额度，足够日常使用
   （如果提示需要开通百炼服务：点"开通服务"，选 **qwen-turbo** 免费即可）

这个 Key 稍后要填到手表上的小北应用里。

---

## 三、获取 APK 安装包（两种方法选其一）

### 方法 A：用 GitHub Actions 云端自动打包（推荐，无需本机装任何工具）

1. 打开 https://github.com/new
2. Repository name 填：`XiaoBeiAssistant`
3. 选 Public（不需要私有仓库）
4. 点 **Create repository**

5. 在本项目目录（`XiaoBeiAssistant` 文件夹）中：
   - 使用 Git 或者直接把本文件夹拖到 https://github.com/upload 上传全部文件

6. 上传完成后，打开仓库页面：
   - 点上面 **Actions** 标签
   - 左侧选 **Build XiaoBei APK**
   - 点右侧 **Run workflow** → 选最新分支 → **Run**

7. 等待约 5 分钟，编译完成。
   - 打开本次运行的页面 → 底部 **Artifacts** 区域
   - 点击下载 **Xiaobei-Assistant-APK** 压缩包

8. 解压后里面有 `app-debug.apk` 就是安装包。

### 方法 B：本机用 Android Studio 打包

如果用 PC 安装了 Android Studio（>= Flamingo 版本），直接：
1. File → Open → 选 `XiaoBeiAssistant` 目录
2. 等待 Gradle 同步完成
3. Build → Build Bundle(s)/APK(s) → Build APK(s)
4. 完成后 APK 在 `app/build/outputs/apk/debug/app-debug.apk`

## 四、安装到华强北手表

1. 将 APK 传到手表：
   - 用蓝牙传（手表支持收文件）、或
   - 从微信/QQ 传到手表、或
   - 用 `adb` 线连手表电脑安装

2. 点击安装。
   - 华强北手表通常允许"未知来源"安装；
   - 若提示不允许，到设置 → 安全 → 打开"允许安装未知应用"。

3. 打开“小北助手”应用。

## 五、首次配置（必须）

### 1. 授予录音权限
打开应用时会看到按钮 → 点击 **“① 下载语音模型”** → 系统会弹出录音权限请求 → 点**允许**。

### 2. 下载离线语音模型（42MB，只需一次）
在应用内点击 **“① 下载语音模型(首次必做)”**
- 需要手表联网（WiFi / 4G）
- 等待进度条到 100%（约 1~10 分钟，看网速）
- 下载完自动解压，显示“模型就绪”

### 3. 填千问 API Key
点击 **“② 设置千问API Key”**
- 粘贴刚才在阿里云百炼复制的 `sk-...`
- 点保存

### 4.（可选项）开机自启
点击 **“③ 开机自启：关”** → 变成 **“开”**
以后每次手表重启，小北会自动在后台待命。

### 5. 开始随叫随到
点击 **“★ 开始随叫随到”**
- 顶部状态显示 **“说「小北 小北」唤醒我”**
- 此时就可以随时说话了！

## 六、日常使用

| 你说 | 小北会 |
|------|--------|
| “小北 小北” | “在呢，请说”（手表轻微震动提醒） |
| “现在几点” | 语音播报当前时间 |
| “我要定个十分钟的闹钟” | 告诉你已设定 |
| “帮我算一下 25×8” | 播报结果 |
| “周杰伦是谁” | 简介 |  
| “今天适合跑步吗” | 基于常识给出建议 |
| “退出” / “没事了” | 返回待命 |

每次回答完，小北会自动回到待命状态，再次说“小北 小北”即可再次对话。

---

## 七、注意事项

1. **电量与常驻**：唤醒监听会保持麦克风开启，会增加一点耗电。不使用时点 **“停止监听(省电)”**。
2. **手表 TTS 声音**：小北播报用的是手表系统自带的文字转语音引擎（中文）。如果播报没声音：
   - 打开设置 → 语言与输入法 → 文字转语音 → 确认中文语音数据已安装
3. **回复简洁**：小北的 AI 被设计成“60字以内 + 口语化”的回答，更适合手表小屏与语音播报。
4. **没有可用的语音引擎时**：个别廉价华强北型号不带中文TTS语音包，需要到应用市场装
   “讯飞语记”或“谷歌文字转语音”并设为默认TTS后小北就有声音了。
5. 若厂商杀后台较强，记得在系统设置里把“小北助手”加入白名单，防止待命被杀。
6. 本项目所有对话均通过网络发送给通义千问。若担心隐私可自行修改 `QwenClient.java` 接入本地模型（但手表性能无法跑本地大模型）。

## 八、技术架构

```
app/
├─ MainActivity.java           主界面（下模型/填Key/启动/日志）
├─ service/
│  ├─ WakeWordService.java     前台服务（保持后台常驻+状态通知）
│  ├─ XiaoBeiEngine.java       语音引擎状态机（唤醒→听→识别→AI→播报）
│  └─ BootReceiver.java        开机自启接收器
├─ ai/
│  └─ QwenClient.java          千问AI HTTP客户端
├─ tts/
│  └─ TtsHelper.java           中文语音播报封装
└─ util/
   ├─ ModelManager.java        Vosk离线模型  下载/解压/校验
   └─ Prefs.java               SharedPreferences 存储

依赖：vosk-android 0.3.47（离线语音识别）
```
